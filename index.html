About LibrePCB

For those who don't know LibrePCB yet, it is a free and open-source, cross-platform PCB design software which aims to be easy to use, to empower everyone creating professional PCBs very quickly.
***
It also features a powerful library concept and a human readable file format which is optimized for version control.

LibrePCB 1.1.0

April 2024

Anyway, let's have a look at what's new in LibrePCB since my last talk at FOSDEM 2 years ago, starting with LibrePCB 1.1.

Live Parts Information

First, we integrated live parts information into LibrePCB. Before you add a component to the schematic, you will see the stock availability and prices of the parts, so you never use parts anymore which have supply chain issues.

You will also see whether a part is active or NRND, and often you also get its datasheet and a picture.

This is all live information, fetched from the internet in the moment you scroll through the list of parts.

And this feature requires no configuration, no API keys, no online account, it just works out of the box.

EAGLE Project Import

Then, we implemented an EAGLE project importer, so if you used EAGLE before, you can now migrate your projects to LibrePCB.

LibrePCB 1.2.0

December 2024

In LibrePCB 1.2,

KiCad Library Import

we also implemented a KiCad library importer, so if you can't find a specific symbol or footprint in the LibrePCB libraries, you could import them from a KiCad library.

Footprint Datasheet Overlay

In the footprint editor it is now possible to overlay a drawing from the datasheet, which is very useful to review a footprint, for example to see if any pad is at a wrong position.

Datasheets in Schematics

Datasheets can now be opened directly from the schematic editor.

Specctra Export / Import

For External Autorouter (e.g. Freerouting)

And since people always ask for an autorouter (I don't know why) we implemented a Specctra export/import, which now at least allows to use an external autorouter.

Mass-Import Pins from Datasheet

Another simple but useful feature is importing pins from a datasheet.

***

Instead of typing all the pin names by hand when you create a new symbol, you can just copy the pinout table from a datasheet, paste it into LibrePCB and LibrePCB automatically extracts the pin names and creates the corresponding pins.

LibrePCB 1.3.0

March 2025

In LibrePCB 1.3 we made some technology updates.

Migration Qt5 → Qt6

We migrated from Qt5 to Qt6, which involved quite some effort,

C++ → Rust

  • Faster development
  • Less error-prone
  • Future-proof

Current state:
0.9% Rust

...and we started to use the Rust programming language in addition to C++.

The main reasons for this step is to increase the speed of development thanks to the huge Rust ecosystem,

to reduce runtime errors and bugs thanks to Rusts compile-time checks and memory safety guarantees,

and in general to move LibrePCB to a future-proof technology instead of staying with C++ which is more and more considered legacy.

However, this is a long way as we are currently at 0.9% Rust code while the rest is still C++.

Interactive HTML BOM Export

The first feature which we implemented in Rust, is a generator for interactive HTML BOMs.

***

This generator is integrated into LibrePCB as an output job, so with just a click you can now export an interactive BOM.

You might know the interactive BOM already from KiCad, where this is available as a plugin, if I remember correctly. In LibrePCB, this is now a built-in feature.

LibrePCB 2.0.0

February 2026

Now, let's get to the interesting part! LibrePCB 2.0 has been released just 4 days ago,

Qt Widgets  →  


  • More freedom, more flexibility
  • Consistent look & feel across platforms
  • Declarative → faster development
  • Aligns with our Rust strategy
...where we made another technology update.

We have rewritten our whole user interface from scratch with a new UI toolkit named Slint.

Compared to Qt Widgets which we used before, Slint gives us much more freedom in the UI design,

ensures a consistent look & feel across all platforms,

speeds up development thanks to a declarative UI description language,

and aligns with our long-term strategy to move from C++ to Rust, as Slint itself is implemented in Rust too.

Tabbed Window

In this new UI, we have also switched to a completely different concept. Instead of having a project management window, schematic editor window, a board editor window, a library editor window and so on, we now have a single window where you can open any kind of document as tabs.

***

So you can open a schematic in one tab, a board in another tab, you can split the window to see tabs next to each other, which is useful on single monitor setups.

On multi monitor setups however, you may just open a second window and move some tabs there, for example the board editor on one monitor and the live 3D viewer on another monitor.

Library Manager

The library manager has been rewritten from scratch too and is now seamlessly integrated into the new window.

In the sidebar you will already see if any of the installed libraries have updates available (***), and in the library manager you will then see which libraries are selected for update.

Here you see all the available libraries and you can just select or deselect the libraries you like to install or to remove. After applying the changes, the libraries are downloaded from the internet and are ready to use.

PCB Ordering

The PCB ordering feature has been integrated into the new window too, and it now automatically informs you about the state of the ERC and DRC messages.

***

If you try to order the PCB without running the DRC first, LibrePCB directly provides the option to run the DRC and displays the result.

After fixing any issues, the upload button is now green and you can proceed with ordering the PCB, which forwards the project to LibrePCB Fab where you can choose the desired PCB manufacturer.

Enhanced 3D Viewer

The 3D viewer also got a small update, which allows you now to hide every physical layer individually to inspect the PCB in more detail.

Schematic Buses

Beside the new UI, LibrePCB now also supports buses to keep the schematics clean,

Images in Schematics

And adding images to schematics, for example to add formulas, diagrams or company logos.

Shared Design Rules & Output Jobs

Also we made it much easier to set up board design rules for specific PCB manufacturers. Design rules can now be stored in libraries, which allows to share design rules through the library manager.

***

In future we plan to add design rules to our official libraries, so the design rules for AISLER, PCBWay and so on will be available out of the box.

***

The same also works for output job settings, so for example you can now just the load Gerber Export settings for PCBway or for AISLER and you don't need to specify those settings manually anymore.

Choose Your Soldering Technique

One challenge of an EDA software is to be suitable for both, the hobbyist with a big solder iron and shaky hands, and the professional engineer creating high density boards.

The hobbyist wants to have large solder pads to make hand soldering easy for him. But for the same device, the engineer wants to have small footprint pads which are suitable for reflow soldering and save space on the board.
***
In LibrePCB 2.0 you can therefore set your preference about the soldering techique, for example hand soldering for through-hole pads and reflow soldering for SMT pads. In addition, you can choose between IPC density levels A, B and C.

Whenever you add a new device to a board, LibrePCB then automatically choses the footprint which matches your preference.

Auto-Reload

For those who are generating LibrePCB symbols and footprints for example with a Python script, you can now use LibrePCB as a live preview of the generated files since it watches for file modifications and automatically reloads modified files from disk.
